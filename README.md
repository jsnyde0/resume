# Jonatan Snyders' Resume Website

This is the source code for my resume website, built with Astro and deployed on Cloudflare Pages. See `DEPLOY.md` for hosting, DNS and rollback.

```bash
npm install
npm run dev    # local dev server
npm run gate   # astro check + build + projects-page check
```

The previous Django version is preserved at the git tag `legacy-django`.
